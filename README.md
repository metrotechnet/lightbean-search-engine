# Lightbeans Search Engine

This repository evaluates and demonstrates product search, retrieval, and texture matching for Lightbeans materials using Meilisearch plus Python-based feature pipelines.

## Project purpose

The codebase supports two main workflows:

- Text search and chat evaluation over Lightbeans catalog data
- Image and texture retrieval using visual embeddings and masked-region matching

The repo is organized around the current scripts in `scripts/text-search/` and `scripts/image-search/`, with generated outputs in `results/`.

## Repository layout

- `data/` — exported catalog data, question sets, evaluation JSON, and prompt/config files
- `images/` — source product/reference imagery used for evaluation and similarity experiments
- `texture/` and `textureAll/` — downloaded texture views and related material assets
- `results/` — outputs generated by search, chat, indexing, and evaluation scripts
- `scripts/text-search/` — Meilisearch product indexing, question search, and chat-based QA
- `scripts/image-search/` — image classification, texture indexing, segmentation, and viewer scripts
- `start-chat.ps1` — convenience launcher that loads `.env` values and runs the chat workflow
- `.env.example` — sample environment configuration for Meilisearch

## Current workflows

### 1) Product search in Meilisearch

The text-search scripts build and query the product catalog and evaluate search quality.

Common commands:

```bash
# create/index product documents
python scripts/text-search/meilisearch_products_manager.py create-index \
  --host http://localhost:7700 \
  --key "$MEILI_KEY" \
  --index lightbeans-products \
  --input data/platform-products-production-v2-en.json

# run keyword search against the indexed data
python scripts/text-search/meilisearch_questions_search.py \
  --host http://localhost:7700 \
  --key "$MEILI_KEY" \
  --index lightbeans-products \
  --input data/meilisearch-search-questions.json \
  --output results/meilisearch-search-results.json

# ask the Meilisearch chat API each question and save answers
python scripts/text-search/meilisearch_questions_chat.py \
  --host http://localhost:7700 \
  --api-key "$MEILI_CHAT_API_KEY" \
  --workspace "$MEILI_CHAT_WORKSPACE" \
  --model "$MEILI_CHAT_MODEL" \
  --input data/meilisearch-search-questions.json \
  --output results/meilisearch-chat-answers.json
```

### 2) Image and texture retrieval

The image-search scripts focus on visual retrieval and texture matching using DINOv2, HSI, and Meilisearch-based indexing.

Representative commands:

```bash
# build a hybrid HSI + DINOv2 texture index in Meilisearch
python scripts/image-search/classification/texture_indexer_hsi_dinov2_meilisearch.py \
  --product-export data/platform-products-production-v2-en.json \
  --textures-dir texture/views \
  --index lightbeans-texture-hsi-dinov2-views

# match a masked region to the texture index
python scripts/image-search/viewer/masked_region_texture_matcher.py \
  --image path/to/input.png \
  --mask path/to/mask.png \
  --index "$MEILI_INDEX" \
  --limit 5

# generate texture views from source images
python scripts/image-search/classification/generate_views.py
```

Other scripts in this area cover:

- `scripts/image-search/crawler/texture_images_downloader.py` — download texture assets from product metadata
- `scripts/image-search/segmentation/sam2_image_segmenter.py` — segment images into candidate regions
- `scripts/image-search/viewer/texture_viewer.py` — browse textures and matches locally

## Setup

1. Copy `.env.example` to `.env` and fill in your Meilisearch settings.
2. Install the Python dependencies needed for the workflow you want to run. Typical packages include:
   - `python-dotenv`
   - `pillow`
   - `numpy`
   - `sentence-transformers`
   - `transformers`
   - `torch`
   - `faiss-cpu` (for local FAISS-based texture search)
3. Run the scripts from the repo root.

Example `.env` values:

```env
MEILI_HOST=https://your-meilisearch-host.example
MEILI_KEY=your-meilisearch-api-key
MEILI_INDEX=lightbeans-products
MEILI_CHAT_API_KEY=your-chat-api-key
MEILI_CHAT_WORKSPACE=your-chat-workspace
MEILI_CHAT_MODEL=gpt-4o-mini
MEILI_CHAT_OUTPUT_PATH=./results/meilisearch-chat-answers.json
INPUT_PATH=./data/meilisearch-search-questions.json
```

## Notes

- `.env` is intentionally local-only and should not be committed.
- The project is designed for experimentation and evaluation rather than as a production web app.
- Search and indexing scripts expect a running Meilisearch instance and the relevant data files under `data/`.
- Some image pipelines require heavier ML dependencies and may need a GPU-enabled environment depending on the model used.

## Useful reference data

- `data/meilisearch-search-questions.json` — benchmark search questions
- `data/platform-products-production-v2-en.json` — Lightbeans product export used by catalog and texture indexing
- `data/ground_truth.json` — ground-truth evaluation mapping
- `data/DINOv2_evaluation_results.json` and related JSONs — model-evaluation outputs

## Quick start

```bash
# 1) Configure environment
cp .env.example .env

# 2) Start the local chat flow using the bundled PowerShell launcher
powershell -ExecutionPolicy Bypass -File ./start-chat.ps1
```

If you are working directly with the scripts, start with the product catalog creation and the search chat scripts, then move on to the image-search experiments.
